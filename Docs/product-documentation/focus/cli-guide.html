Runtime Path Model

  • CLI resolves paths in runtime and defaults to workspace-native directories under Workspaces/<view>.
  • You can override paths with --inputs-dir, --config-dir, and --output-dir.
  • Lineage cache defaults to <output-dir>/_cache/taxonomy_lineage_db.json.

Implementation: cli.py path functions and command handlers.

Main Commands

python askslm.py metadata-overview --view ABX
python askslm.py abundance-matrix --view ABX
python askslm.py build-taxonomy-lineage --view ABX
python askslm.py alpha-diversity --view ABX --rank genus
python askslm.py taxonomic-abundance --view ABX --rank genus --taxon Prevotella
python askslm.py single-taxon-abundance --view ABX --rank superkingdom --taxon Viruses --source-keys sample_name host_subject_id_sam

Important Guardrail

  • alpha-diversity requires the lineage DB file.
  • If missing, CLI exits with a remediation message telling you to run build-taxonomy-lineage first.
