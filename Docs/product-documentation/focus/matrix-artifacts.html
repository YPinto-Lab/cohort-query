Runner Pipeline Artifacts (Notebook Workflow)

Artifact Created In Saved Path How It Is Built
Abundance Matrix compute_taxonomy_matrices in Engines/DatasetAssemblyEngine/dataset_assembly_engine.py (called by run_taxonomy_stage) Workspaces/<workspace>/results/Ask_SLM_Taxon_Abundance_Matrix.csv Resolves deprecated NCBI tax IDs via a required merged.dmp input, then groups rows by acc and taxon_key, sums total_count, and pivots to sample x taxon_key.
Abundance-Metadata Matrix compute_analysis_wide_dataset in Engines/DatasetAssemblyEngine/dataset_assembly_engine.py (called by run_merge_stage) Workspaces/<workspace>/results/Ask_SLM_Analysis_Wide_Dataset.csv Left-joins enriched metadata with abundance matrix on acc and fills taxa feature nulls with 0.

Related artifacts: Ask_SLM_Taxon_Lookup.csv, Ask_SLM_Metadata_Columns.json, Ask_SLM_Taxonomy_Resolution_Summary.json, Ask_SLM_Taxonomy_Resolution_Changes.csv, merge/taxonomy stamps in results/_cache. run_taxonomy_stage requires an explicit merged.dmp path (for example Accessors/TaxonomyAccessor/merged.dmp) and does not use fallback discovery.

Detailed behavior and stage order: see Docs/product-documentation/focus/taxonomy-resolution-flow.md.

CLI Abundance Matrix (Command Workflow)

The CLI command abundance-matrix builds a separate matrix directly from taxonomy name values (not the runner taxon_key matrix).

Command Created In Saved Path
python askslm.py abundance-matrix --workspace <workspace> cmd_abundance_matrix in cli.py Workspaces/<workspace>/results/abundance_matrix/abundance_matrix.csv

Quick Interpretation

  • Runner abundance matrix is the canonical feature matrix for downstream merge and interactive engines.
  • Runner abundance-metadata matrix is the canonical analysis-wide dataset consumed by notebook interactive analysis.
  • CLI abundance-matrix output is a command-specific export and is not the same file as Ask_SLM_Taxon_Abundance_Matrix.csv.
