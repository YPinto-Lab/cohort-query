    A. High-Level Design

    A.1 Architectural style

    A small layered / hexagonal package. The domain core knows nothing about DuckDB, Gemini, or the filesystem; those are adapters behind ports. The composition root (Runtime) connects concretes to ports. The Jupyter-facing functions (config, ask, load_plan) are a thin facade — no logic.

    Domain depends on nothing. Services depend on domain + ports. Adapters implement ports. This seam lets every service be unit-tested against fakes, and lets the LLM provider, the database engine, or a whole new source be swapped/added without touching the core.

    A.2 Layers & responsibilities

    A.3 The two ports

    The Database adapter queries a prebuilt DuckDB over SQL — it never reads raw files. This is a deliberate decision, not an accident of the v1 implementation. The Metalog/SRA files (gzipped TSVs, parquet) are parsed once into a columnar askslm_mirror.duckdb by a separate ETL; the package only ever opens that mirror read-only and runs the LLM's SQL against it. The rejected alternative — read_csv over the raw files at query time — re-parses multi-GB gzip on every call and was ruled out for speed. Build-time reads files; run-time queries DuckDB. Rationale and the A/B/C trade-off: Docs/superpowers/plans/2026-06-18-metalog-duckdb-build.md.

    A.4 Sources & feature universes core model

    One source = one DuckDB table. A database (SRA, Metalog) contributes several. Every source has a kind that decides how multiples of it combine:

    KindSourcesRole in the biomHow multiples combine
    METADATASRA_METADATA, METALOG_METADATAdescribe the samples (sample axis)reconciled per field by precedence (A.6)
    PROFILESRA_TAXONOMY, METALOG_METAPHLAN4_ALL, METALOG_METAPHLAN4_SPECIES, METALOG_MOTUS3, METALOG_SPIRE_MOTUSfeed the counts (feature axis)within one feature universe, per sample (whole-column), normalized to relative abundance

    A PROFILE source also carries a FeatureUniverse — the feature-ID namespace it speaks. Two sources can only share a biom if they share a universe:

    FeatureUniverseFeature IDMember sourcesHow they align
    NCBI_TAXONOMYNCBI tax_idSRA_TAXONOMY (STAT) · METALOG_METAPHLAN4_ALL · METALOG_METAPHLAN4_SPECIESan NCBI tax_id maps to a MetaPhlAn clade (tax_id → clade, not the reverse) — STAT's tax_ids align onto MetaPhlAn's clades
    MOTUSmOTU IDMETALOG_MOTUS3 · METALOG_SPIRE_MOTUSshared mOTU IDs, directly
    One biom = one universe. The profile_winning_source names the universe; the other sources of that universe fill the samples it lacks (whole-column, never half-STAT/half-MetaPhlAn). Counts are normalized to relative abundance so columns compare even across native units (STAT counts vs MetaPhlAn %). Because the universe is derived from the winner, cross-universe mixing is structurally impossible — mOTU IDs and NCBI tax_ids never share a biom.

    The flat list mirrors how the data ships (one table per metadata set and per profiler). Extension is one row: a new database, metadata set, or profiler is just a new Source (with its universe).

    A.5 Sample identity confirmed against the data

    The canonical key is the NCBI BioSample (SAMN…) — the biom's columns are biosamples. The two-hop bridge (Metalog profiles use a study-internal name, not an external accession) is resolved once, at build time, so every table in the mirror already carries a biosample column. The package then sees one primary key across all sources — run-time never re-derives it:

    WhenWhat happens
    Build (ETL, once)resolve profile.sample_alias → metalog_metadata.sample_alias, then spire_sample_name == sra_metadata.biosample; stamp the resolved biosample onto every Metalog table and index it. The two-hop lives here and nowhere else.
    Run (per query)every source — SRA and Metalog — already exposes biosample; joins are single-key. No AccessionNormalizer, no per-query bridge.

    One key, with one honest exception. Because Metalog keeps its own ids (an external accession isn't always 1:1 with a sample) and spire_sample_name is mixed-type, some Metalog samples resolve to no biosample:

    IdentifierRoleNull?
    sample_aliasMetalog's internal PK — always present, unambiguousnever
    biosamplethe cross-source join key (resolved at build, indexed everywhere)NULL for the Metalog-only tail with no external BioSample
    Column-id rule. A biom column is keyed by its biosample when present; for the null tail (Metalog-only, no BioSample — nothing to join to anyway) it falls back to sample_alias. So "one key across all sources" holds for everything that can be shared, without inventing biosamples for orphans.

    A.6 Overlap & the cohort partition core model

    Discovery runs each source's query — every row already carries its biosample (stamped at build, A.5) — and partitions the cohort by where each biosample appears. That partition is what plan shows and what run() resolves:

    PartitionBiosample appears inMetadata comes fromCounts come from
    SRA-onlySRA query onlySRAthe universe's SRA source
    Metalog-onlyMetalog query onlyMetalogthe universe's Metalog source(s)
    sharedbothmetadata_winning_source decidesprofile_winning_source's column wins

    A.7 The public API revised

    Two verbs. ask() understands the question and previews the cohort — no source choices, no biom presupposed. run() materializes a biom and is the only place the two winning sources (which PROFILE source heads the counts universe, which METADATA source wins ties) are named.

    The calls

    # configure once
askslm.config(db="/mnt/lab/metalog_sra.duckdb", llm="gemini", llm_key=os.environ["..."])

# understand + preview (one LLM hop + cheap COUNTs). Persists the plan to disk.
plan = askslm.ask("fecal metagenomes from adults with IBD, Western countries", save="plans/ibd.json")
plan                       # renders the show-your-work below; stats-only users stop here

table = plan.run(profile_winning_source=askslm.Source.METALOG_METAPHLAN4_SPECIES,
                 metadata_winning_source=askslm.Source.METALOG_METADATA,   # default
                 out="cohort.biom")                                # prints the overview below, returns a biom.Table

# reproduce later — same cohort, a different universe, no LLM call:
askslm.load_plan("plans/ibd.json").run(profile_winning_source=askslm.Source.METALOG_MOTUS3, out="cohort_motus.biom")

    B.2 Domain value objects (frozen dataclasses)

    Accession = NewType("Accession", str)   # canonical (biosample-level) id — the join key

class SourceKind(Enum):
    METADATA = "metadata"          # reconcilable across sources by precedence (per field)
    PROFILE  = "profile"           # feeds counts; lives in a FeatureUniverse

class FeatureUniverse(Enum):
    NCBI_TAXONOMY = "ncbi_taxonomy"   # NCBI tax_id — STAT + MetaPhlAn4
    MOTUS         = "motus"           # mOTU IDs — mOTUs3 + SPIRE

class Unit(Enum):
    COUNTS   = "counts"             # normalized to RELATIVE on materialization
    RELATIVE = "relative"

@dataclass(frozen=True)
class SourceSpec:
    database: str                # provenance: "sra" | "metalog"
    table: str
    kind: SourceKind
    universe: FeatureUniverse | None = None   # set for PROFILE sources
    unit: Unit | None = None                  # native unit of a PROFILE source
    lineage_column: str | None = None         # set for PROFILE sources

@dataclass(frozen=True)
class ResearchQuestion:
    text: str                    # the whole question; source-agnostic

@dataclass(frozen=True)
class SourceQuery:
    source: Source
    sql: str

@dataclass(frozen=True)
class Translation:                # LlmBackend output, before any DB hit
    interpretation: QueryInterpretation
    queries: tuple[SourceQuery, ...]    # one per source — add a source, add an entry

@dataclass(frozen=True)
class CohortPreview:              # the show-your-work numbers
    by_metadata_source: dict[Source, int]   # the partition — who has the sample
    shared: int                  # in >1 metadata source — the overlaps
    union: int
    by_profile_source: dict[Source, int]    # coverage per PROFILE source — pick one to head its universe

@dataclass(frozen=True)
class Materialization:           # the two run() choices, grouped + validated
    profile_winning_source: Source
    metadata_winning_source: Source

    def __post_init__(self):
        require(self.profile_winning_source.kind() is SourceKind.PROFILE,  "profile_winning_source must be a PROFILE source")
        require(self.metadata_winning_source.kind() is SourceKind.METADATA, "metadata winner must be a METADATA source")

    def universe(self) -> FeatureUniverse:
        return self.profile_winning_source.spec().universe   # the biom's one universe, derived

    B.3 Source — every table, one flat enum

    Each member carries its SourceSpec. This is the only place a source maps to a table — adding a database, metadata set, or profiler means adding one member here, nowhere else.

    class Source(Enum):
    # database, table, kind[, universe, unit, lineage_column]
    SRA_METADATA               = SourceSpec("sra",     "sra_metadata",       SourceKind.METADATA)
    METALOG_METADATA           = SourceSpec("metalog", "metalog_metadata",   SourceKind.METADATA)
    SRA_TAXONOMY               = SourceSpec("sra",     "sra_taxonomy",       SourceKind.PROFILE, FeatureUniverse.NCBI_TAXONOMY, Unit.COUNTS,   "lineage")
    METALOG_METAPHLAN4_ALL     = SourceSpec("metalog", "metaphlan4_all",     SourceKind.PROFILE, FeatureUniverse.NCBI_TAXONOMY, Unit.RELATIVE, "clade")
    METALOG_METAPHLAN4_SPECIES = SourceSpec("metalog", "metaphlan4_species", SourceKind.PROFILE, FeatureUniverse.NCBI_TAXONOMY, Unit.RELATIVE, "clade")
    METALOG_MOTUS3             = SourceSpec("metalog", "motus3",             SourceKind.PROFILE, FeatureUniverse.MOTUS,         Unit.RELATIVE, "clade")
    METALOG_SPIRE_MOTUS        = SourceSpec("metalog", "spire_motus",        SourceKind.PROFILE, FeatureUniverse.MOTUS,         Unit.RELATIVE, "clade")

    def kind(self) -> SourceKind:
        return self.value.kind

    def spec(self) -> SourceSpec:
        return self.value

    PROFILE members grouped by universe: NCBI_TAXONOMY (STAT counts + the two MetaPhlAn relative profiles) and MOTUS (mOTUs3 + SPIRE). Materialization.universe() reads it back from the chosen winner.

    B.5 Identity — Cohort

    There is no run-time normalizer: the biosample key is materialized at build (A.5), so every query already returns it. Accession is just the resolved biosample (or the sample_alias fallback for the null tail). Cohort is therefore pure set logic over keys that arrive ready:

    @dataclass(frozen=True)
class Cohort:
    by_source: dict[Source, frozenset[Accession]]    # metadata sources that returned each biosample

    def union(self) -> frozenset[Accession]:
        return frozenset().union(*self.by_source.values())

    def shared(self) -> frozenset[Accession]:
        return self._appearing_in_more_than_one()      # the overlaps

    def only(self, source: Source) -> frozenset[Accession]:
        others = self.union() - self.by_source[source]
        return self.by_source[source] - others

    B.6 Translation — Translator + GeminiBackend

    @dataclass(frozen=True)
class TranslationPrompt:
    question: ResearchQuestion
    schemas: str                     # every source's columns, from SchemaCatalog

class Translator:
    def __init__(self, backend: LlmBackend, catalog: SchemaCatalog):

    Invalid SQL surfaces when CohortPreviewBuilder runs the counts (B.8), not here — keeping the network step pure.

    B.7 Plan, PlanView, PlanRepository

    @dataclass(frozen=True)
class Plan:
    question: ResearchQuestion
    translation: Translation
    preview: CohortPreview
    error: str | None = None

    def run(self, profile_winning_source: Source, out: Path,
            metadata_winning_source: Source = Source.METALOG_METADATA) -> biom.Table:
        self._guard_runnable()
        request = Materialization(profile_winning_source=profile_winning_source,
                                  metadata_winning_source=metadata_winning_source)
        return active_runtime().cohort_builder().build(self, request, out)

    def _guard_runnable(self):
        if self.error is not None:
            raise TranslationError(self.error)

    def _repr_html_(self) -> str:
        return PlanView(self).render()

    The source choices are not stored on the Plan — they are run() arguments, so one persisted plan materializes many ways. run() bundles them into a validated Materialization so CohortBuilder.build(plan, request, out) stays at three params. The ambient active_runtime() (service locator) is accepted because load_plan(path).run() must work from a bare file.

    class PlanRepository:
    def __init__(self, root: Path):
        self._root = root

    def save(self, plan: Plan, path: Path | None) -> Path:
        target = self._resolve(path, plan.question)   # explicit save= or plans/<slug>.json
        target.write_text(self._encode(plan))
        return target

    def load(self, path: Path) -> Plan:
        return self._decode(path.read_text())

    B.8 AskService & CohortPreviewBuilder

    class AskService:
    def __init__(self, translator: Translator, previews: CohortPreviewBuilder, repository: PlanRepository):
        self._translator = translator
        self._previews = previews
        self._repository = repository

    def ask(self, question: ResearchQuestion, save: Path | None) -> Plan:
        translation = self._translator.translate(question)
        plan = self._planned(question, translation)
        self._repository.save(plan, save)
        return plan

    def _planned(self, question: ResearchQuestion, translation: Translation) -> Plan:
        preview = self._previews.preview(translation)
        return Plan(question=question, translation=translation, preview=preview)

    CohortPreviewBuilder runs cheap aggregates only: per metadata-source accession counts, the overlap (shared) size, and a coverage count for every PROFILE source. It is also where invalid SQL is caught — the count fails and the Plan is returned carrying error, so review still renders and run() refuses.

    B.9 The cohort engine — CohortBuilder and collaborators

    class CohortBuilder:
    def __init__(self, discovery: CohortDiscovery, profiles: ProfileReconciler,
                 metadata: MetadataReconciler, factory: BiomFactory):
        self._discovery = discovery
        self._profiles = profiles
        self._metadata = metadata
        self._factory = factory

    def build(self, plan: Plan, request: Materialization, out: Path) -> biom.Table:
        cohort = self._discovery.discover(plan.translation.queries)
        matrix = self._profiles.read(request.profile_winning_source, cohort.union())
        metadata = self._metadata.reconciled(cohort, request.metadata_winning_source)
        table = self._factory.build(matrix, metadata.restricted_to(matrix.accessions()))
        return self._written(table, out, DropReport.between(cohort.union(), matrix.accessions()))
    ClassSignatureDomain effect
    CohortDiscoverydiscover(queries) -> Cohortrun each query (rows already carry the build-stamped biosample), group by metadata source into a Cohort that knows its overlaps. No normalization step.
    ProfileReaderread(profile_source, accessions) -> ProfileMatrixpull one PROFILE source's table; matrix columns are the samples that actually have it.
    ProfileReconcilerread(profile_winning_source, accessions) -> ProfileMatrixread every source of the winner's universe, normalize each to relative abundance, fold by precedence at whole-column granularity (winner's column wins, others fill missing samples).
    MetadataReaderread(source, accessions) -> DataFrameread ONE metadata source's frame for the cohort — the mirror of ProfileReader.
    MetadataReconcilerreconciled(cohort, winning_source) -> ReconciledMetadataorchestrate: read every metadata source via MetadataReader, fold per field by precedence (winner heads it) — the mirror of ProfileReconciler.
    BiomFactorybuild(matrix, metadata) -> biom.Tableassemble the single-feature-space table; lineage on the feature axis.
    DropReportbetween(requested, present) -> DropReportset difference: cohort samples with no profile, reported never silently kept.

    B.10 Precedence merge — and 3+-source ties

    Reconciliation uses a total precedence order, never just "winner vs the rest." The chosen winning_source is promoted to the head; the remaining metadata sources fall back to one explicit DEFAULT_PRECEDENCE. So a conflict between two non-winning sources is resolved by whichever ranks higher there — never an undefined tie. (With today's two metadata sources the winner fully determines it; this only matters at three or more.)

    class MetadataReconciler:                                # orchestrator — mirror of ProfileReconciler
    DEFAULT_PRECEDENCE = (Source.METALOG_METADATA, Source.SRA_METADATA)   # tie-break among non-winning sources

    def __init__(self, reader: MetadataReader):
        self._reader = reader

    def reconciled(self, cohort: Cohort, winning_source: Source) -> ReconciledMetadata:
        frames = {s: self._reader.read(s, cohort.union()) for s in cohort.by_source}
        ordered = self._ordered(frames, winning_source)
        return ReconciledMetadata(self._folded(ordered))

    def _ordered(self, frames: dict[Source, pandas.DataFrame], winning_source: Source) -> list[pandas.DataFrame]:
        rest = [s for s in self.DEFAULT_PRECEDENCE if s is not winning_source]
        present = [s for s in [winning_source, *rest] if s in frames]
        return [frames[s] for s in present]

    def _folded(self, ordered: list[pandas.DataFrame]) -> pandas.DataFrame:
        return reduce(combine_first_onto, ordered[1:], ordered[0])   # each later frame only fills gaps

    Frames indexed by Accession; combine_first is exactly "left wins, right fills," so folding head→tail makes the head win and each lower-ranked source fill only the gaps. No else, no lambda — combine_first_onto is a named module function.

    Profiles — same universe, per-sample (whole-column) fill

    ProfileReconciler is the same precedence idea for counts, with two differences: it stays inside the winner's FeatureUniverse, and it folds at sample granularity (a whole column comes from one source — never half-STAT/half-MetaPhlAn). Each source is normalized to relative abundance first, so columns are comparable.

    class ProfileReconciler:
    DEFAULT_PRECEDENCE = {
        FeatureUniverse.NCBI_TAXONOMY: (Source.METALOG_METAPHLAN4_SPECIES, Source.SRA_TAXONOMY),
        FeatureUniverse.MOTUS:         (Source.METALOG_MOTUS3, Source.METALOG_SPIRE_MOTUS),
    }

    def read(self, winning_source: Source, accessions: frozenset[Accession]) -> ProfileMatrix:
        ordered = self._universe_order(winning_source)
        columns = [self._relative(s, accessions) for s in ordered]
        return ProfileMatrix.fold_by_sample(columns)   # winner's column wins; others fill missing samples

    def _universe_order(self, winning_source: Source) -> list[Source]:
        universe = winning_source.spec().universe
        rest = [s for s in self.DEFAULT_PRECEDENCE[universe] if s is not winning_source]
        return [winning_source, *rest]

    def _relative(self, source: Source, accessions: frozenset[Accession]) -> ProfileColumns:
        native = self._reader.read(source, accessions)    # ProfileReader → native unit (counts or relative)
        return normalize_to_relative(native, source.spec().unit)   # counts → per-sample proportions

    Only the winner's universe appears in DEFAULT_PRECEDENCE[universe], so cross-universe mixing cannot happen by construction. normalize_to_relative and fold_by_sample are named functions — no lambda.

    B.11 ProfileMatrix / ReconciledMetadata

    @dataclass(frozen=True)
class ProfileMatrix:
    counts: pandas.DataFrame          # features × accessions, one feature space
    lineage: pandas.DataFrame         # feature → lineage; the biom feature axis

    def accessions(self) -> frozenset[Accession]:
        return frozenset(self.counts.columns)

@dataclass(frozen=True)
class ReconciledMetadata:
    frame: pandas.DataFrame           # indexed by Accession

    def restricted_to(self, accessions: frozenset[Accession]) -> ReconciledMetadata:
        return ReconciledMetadata(self.frame.loc[sorted(accessions)])
