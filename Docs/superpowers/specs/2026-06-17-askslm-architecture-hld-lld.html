    A. High-Level Design

    A.1 Architectural style

    A small layered / hexagonal package. The domain core knows nothing about DuckDB, Gemini, or the filesystem; those are adapters behind ports. The composition root (Runtime) connects concretes to ports. The Jupyter-facing functions (config, ask, load_plan) are a thin facade — no logic.

    Domain depends on nothing. Services depend on domain + ports. Adapters implement ports. This seam lets every service be unit-tested against fakes, and lets the LLM provider, the database engine, or a whole new source be swapped/added without touching the core.

    A.4 Sample identity & overlap core model

    The whole product rests on one idea: the same biological sample can appear in more than one source, and we recognize it by its accession. Metalog records each sample's ENA/SRA accession; equality on the canonical accession is how SRA and Metalog rows are matched.

    • Join key = canonical accession. Sources are matched by accession, not by re-sequencing or fuzzy metadata. AccessionNormalizer maps each source's raw identifier to one canonical level (ENA/NCBI prefix and run-vs-sample differences are normalized first).
    • Identity level confirm: "a sample" = the biosample-level accession (a biological sample), not the run — one biosample may have several runs, and meta-analysis compares samples. The biom's columns are biosamples.
    • Profiler ≠ source, but a profiler is source-bound. A source is provenance (SRA, Metalog); a profiler is the method that produced counts. Each profiler already names its source (ProfilerSpec.source), so choosing a profiler chooses the count provenance — counts have a single axis. Metadata is the only thing with an independent source axis (both sources describe the same sample), which is why the metadata winner is the one reconciliation choice.

    A.5 The public API revised

    Two verbs. ask() understands the question and previews the cohort — no profiler, no winner, source-agnostic. run() materializes a biom and is the only place the two materialization choices (which feature space, which source wins metadata) are made.

    # configure once
askslm.config(db="/mnt/lab/metalog_sra.duckdb", llm="gemini", llm_key=os.environ["..."])

# understand + preview (one LLM hop + cheap COUNTs). Persists the plan to disk.
plan = askslm.ask("fecal metagenomes from adults with IBD, Western countries", save="plans/ibd.json")

plan        # show-your-work: interpretation, per-source SQL, AND the overlap partition + coverage:
            #   cohort 412 — SRA-only 205, Metalog-only 32, shared 175
            #   profiler coverage: metaphlan4_species 207, motus3 207, sra_taxonomy 380

# stats only? stop here — no profiler, no materialization needed.

# materialize: feature space + metadata winner chosen HERE.
table = plan.run(profiler=askslm.Profiler.METAPHLAN4_SPECIES,
                 metadata_winning_source=askslm.Source.METALOG,   # default; resolves the 175 shared samples
                 out="cohort.biom")

# reproduce later — same cohort, different choices, no LLM call:
askslm.load_plan("plans/ibd.json").run(profiler=askslm.Profiler.MOTUS3, out="cohort_motus.biom")
    Why this shape. The research question is independent of how counts are rendered and of which source wins a metadata tie. One plan can be materialized many ways without re-asking. A future database adds Sources/Profilers; ask()'s signature never moves.

    A.6 Control flow — three sequences

    ask() — translate, preview (incl. overlap), persist

    plan.run(profiler, metadata_winning_source, out) — discover, pull, reconcile, assemble

    load_plan(path).run(...) — reproduce without the LLM

@dataclass(frozen=True)
class Cohort:
    by_source: dict[Source, frozenset[Accession]]

    def union(self) -> frozenset[Accession]:
        return frozenset().union(*self.by_source.values())

    def shared(self) -> frozenset[Accession]:
        return self._appearing_in_more_than_one()      # the overlaps

    def only(self, source: Source) -> frozenset[Accession]:
        others = self.union() - self.by_source[source]
        return self.by_source[source] - others

    B.6 Plan, PlanView, PlanRepository

    @dataclass(frozen=True)
class Plan:
    question: ResearchQuestion
    translation: Translation
    preview: CohortPreview
    error: str | None = None

    def run(self, profiler: Profiler, out: Path,
            metadata_winning_source: Source = Source.METALOG) -> biom.Table:
        self._guard_runnable()
        request = Materialization(profiler=profiler, metadata_winning_source=metadata_winning_source)
        return active_runtime().cohort_builder().build(self, request, out)

    def _guard_runnable(self):
        if self.error is not None:
            raise TranslationError(self.error)

    def _repr_html_(self) -> str:
        return PlanView(self).render()

    The profiler and winner are not stored on the Plan — they are run() arguments, so one persisted plan materializes many ways. run() bundles them into a Materialization so CohortBuilder.build(plan, request, out) stays at three params. Tradeoff on the ambient active_runtime() (service locator) is unchanged from the prior revision: accepted because load_plan(path).run() must work from a bare file.

    class PlanRepository:
    def __init__(self, root: Path):
        self._root = root

    def save(self, plan: Plan, path: Path | None) -> Path:
        target = self._resolve(path, plan.question)   # explicit save= or plans/<slug>.json
        target.write_text(self._encode(plan))
        return target

    def load(self, path: Path) -> Plan:
        return self._decode(path.read_text())

    B.7 AskService & CohortPreviewBuilder

    class AskService:
    def __init__(self, translator: Translator, previews: CohortPreviewBuilder, repository: PlanRepository):
        self._translator = translator
        self._previews = previews
        self._repository = repository

    def ask(self, question: ResearchQuestion, save: Path | None) -> Plan:
        translation = self._translator.translate(question)
        plan = self._planned(question, translation)
        self._repository.save(plan, save)
        return plan

    def _planned(self, question: ResearchQuestion, translation: Translation) -> Plan:
        preview = self._previews.preview(translation)
        return Plan(question=question, translation=translation, preview=preview)

    CohortPreviewBuilder runs cheap aggregates only: per-source accession counts, the overlap (shared) size, and a coverage count for every profiler. It is also where invalid SQL is caught — the count fails and the Plan is returned carrying error, so review still renders and run() refuses.

    B.8 The cohort engine — CohortBuilder and collaborators

    class CohortBuilder:
    def __init__(self, discovery: CohortDiscovery, profiles: ProfileReader,
                 metadata: MetadataReader, factory: BiomFactory):
        self._discovery = discovery
        self._profiles = profiles
        self._metadata = metadata
        self._factory = factory

    def build(self, plan: Plan, request: Materialization, out: Path) -> biom.Table:
        cohort = self._discovery.discover(plan.translation.queries)
        matrix = self._profiles.read(request.profiler, cohort.union())
        metadata = self._metadata.reconciled(cohort, request.metadata_winning_source)
        table = self._factory.build(matrix, metadata.restricted_to(matrix.accessions()))
        return self._written(table, out, DropReport.between(cohort.union(), matrix.accessions()))
    ClassSignatureDomain effect
    CohortDiscoverydiscover(queries) -> Cohortrun every source SELECT, normalize accessions, group into per-source sets (a Cohort that knows its overlaps).
    ProfileReaderread(profiler, accessions) -> ProfileMatrixpull the chosen profiler's table; matrix columns are the samples that actually have it.
    MetadataReaderreconciled(cohort, winning_source) -> ReconciledMetadataread each source's metadata, fold with the winning source at the head.
    MetadataReconcilerreconcile(frames, winning_source) -> ReconciledMetadatatotal precedence order: winning source wins, then DEFAULT_PRECEDENCE fills gaps.
    BiomFactorybuild(matrix, metadata) -> biom.Tableassemble the single-feature-space table; lineage on the feature axis.
    DropReportbetween(requested, present) -> DropReportset difference: cohort samples with no profile, reported never silently kept.

    B.9 Precedence merge — and 3+-source ties

    Reconciliation uses a total precedence order, never just "winner vs the rest." The chosen winning_source is promoted to the head; the remaining sources fall back to one explicit DEFAULT_PRECEDENCE. So a conflict between two non-winning sources is resolved by whichever ranks higher there — there is never an undefined tie. (With today's two sources the winner fully determines it; this only matters at three or more.)

    class MetadataReconciler:
    DEFAULT_PRECEDENCE = (Source.METALOG, Source.SRA)    # total order; the tie-break among non-winning sources

    def reconcile(self, frames: dict[Source, pandas.DataFrame], winning_source: Source) -> ReconciledMetadata:
        ordered = self._ordered(frames, winning_source)
        return ReconciledMetadata(self._folded(ordered))

    def _ordered(self, frames: dict[Source, pandas.DataFrame], winning_source: Source) -> list[pandas.DataFrame]:
        rest = [s for s in self.DEFAULT_PRECEDENCE if s is not winning_source]
        present = [s for s in [winning_source, *rest] if s in frames]
        return [frames[s] for s in present]

    def _folded(self, ordered: list[pandas.DataFrame]) -> pandas.DataFrame:
        return reduce(combine_first_onto, ordered[1:], ordered[0])   # each later frame only fills gaps

    Frames indexed by Accession; combine_first is exactly "left wins, right fills," so folding head→tail makes the head win and each lower-ranked source fill only the gaps left. No else, no lambda — combine_first_onto is a named module function.

    B.10 ProfileMatrix / ReconciledMetadata

    @dataclass(frozen=True)
class ProfileMatrix:
    counts: pandas.DataFrame          # features × accessions, one feature space
    lineage: pandas.DataFrame         # feature → lineage; the biom feature axis

    def accessions(self) -> frozenset[Accession]:
        return frozenset(self.counts.columns)

@dataclass(frozen=True)
class ReconciledMetadata:
    frame: pandas.DataFrame           # indexed by Accession

    def restricted_to(self, accessions: frozenset[Accession]) -> ReconciledMetadata:
        return ReconciledMetadata(self.frame.loc[sorted(accessions)])

    B.12 Testing strategy

    • Ports get fakes. FakeLlmBackend / FakeDatabase; every service unit-tested with zero network/disk. AAA, blank-line-separated.
    • Domain objects are pure — Cohort.shared/only, the winner-fold, DropReport.between, restricted_to tested on small fixtures.
    • One e2e against a tiny fixture DuckDB (a few accessions overlapping across both sources, two profilers): asserts the partition, the biom feature space, the dropped set, and winner-driven metadata.
    • Plan round-trip: save → load → equal Plan; load_plan(path).run(...) never touches LlmBackend and accepts different profiler/winner than any earlier run.
