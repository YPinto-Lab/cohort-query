A. High-Level Design

A.1 Architectural style

A small layered / hexagonal package. The domain core knows nothing about DuckDB, Gemini, or the filesystem; those are adapters behind ports. One wiring point (Runtime) connects concretes to ports. The Jupyter-facing functions (config, ask, load_plan) are a thin facade — no logic.

Domain depends on nothing. Services depend on domain + ports. Adapters implement ports. This is the seam that lets every service be unit-tested against fakes, and lets the LLM provider or the database engine be swapped — or a new database be added — without touching the core.

A.3 The two ports

Everything that touches the network (the LLM) or the disk (the DuckDB file) lives behind one of two single-method ports. The readers are composed from Database — they are domain logic expressed as SQL, not new I/O boundaries.

A.4 The public API revised

Two verbs. ask() understands the question and previews the cohort — no profiler, source- agnostic, no biom presupposed. run() materializes a biom and is the only place a feature space (profiler) is chosen.

# configure once
askslm.config(db="/mnt/lab/metalog_sra.duckdb", llm="gemini", llm_key=os.environ["..."])

# understand + preview (one LLM hop + cheap COUNTs). Persists the plan to disk.
plan = askslm.ask("fecal metagenomes from adults with IBD, Western countries", save="plans/ibd.json")

plan        # show-your-work: interpretation, the per-source SQL, cohort size,
            # and per-profiler coverage so Noam can pick — e.g.
            # cohort 412 (SRA 380 ∪ Metalog 207); metaphlan4_species 207, motus3 207, sra_taxonomy 380

# stats only? stop here — never needed a profiler.

# materialize: feature space chosen HERE, at the build step.
table = plan.run(profiler=askslm.Profiler.METAPHLAN4_SPECIES, out="cohort.biom")

# reproduce later without the LLM:
askslm.load_plan("plans/ibd.json").run(profiler=askslm.Profiler.MOTUS3, out="cohort_motus.biom")
Why this is better. The research question is independent of how you render counts. One plan can be materialized in several feature spaces (try mOTUs and MetaPhlAn from the same cohort) without re-asking. A future database adds Sources and Profilers; ask()'s signature never moves.

A.5 Control flow — three sequences

ask() — translate, size, persist

plan.run(profiler, out) — discover, pull, reconcile, assemble

load_plan(path).run(profiler, out) — reproduce without the LLM

A.7 Reuse from the existing codebase

  • sra_schema.py (SRAMetadataSchema, SRATaxonomySchema) feeds SchemaCatalog — the column inventory the LLM is grounded on.
  • The current biom build path (counts + lineage feature metadata + sample metadata) is wrapped by BiomFactory; the assembly rules do not change.
  • Reconciliation keeps two DataFrames (standing rule): metadata and lineage never merge. ReconciledMetadata is sample metadata only; lineage rides the biom feature axis.

B. Low-Level Design

B.1 Domain value objects (frozen dataclasses)

Everything crossing a seam is a typed domain object, never bare str/dict/ DataFrame. Accession is a NewType(str); the real object is Cohort, which owns the set semantics. Note ResearchQuestion carries only the text — no profiler — and Translation carries N source queries.

Accession = NewType("Accession", str)

class Source(Enum):
    SRA = "sra"
    METALOG = "metalog"

@dataclass(frozen=True)
class ResearchQuestion:
    text: str                        # the whole question; source- and profiler-agnostic

@dataclass(frozen=True)
class SourceQuery:
    source: Source
    sql: str

@dataclass(frozen=True)
class QueryInterpretation:
    restatement: str                 # one English line per understood filter
    filters: tuple[str, ...]

@dataclass(frozen=True)
class Translation:                    # LlmBackend output, before any DB hit
    interpretation: QueryInterpretation
    queries: tuple[SourceQuery, ...] # one per source — add a DB, add an entry

@dataclass(frozen=True)
class CohortPreview:                  # the show-your-work numbers
    by_source: dict[Source, int]
    union: int
    by_profiler: dict[Profiler, int] # coverage so Noam picks the feature space

B.2 Profiler — the closed set, single source of truth

Each member carries its ProfilerSpec: which source, which DuckDB table, which lineage column. This is the only place a profiler maps to a table — adding a database means adding members here, nowhere else.

@dataclass(frozen=True)
class ProfilerSpec:
    source: Source
    table: str
    lineage_column: str

class Profiler(Enum):
    SRA_TAXONOMY       = ProfilerSpec(Source.SRA,     "sra_taxonomy",      "lineage")
    MOTUS3             = ProfilerSpec(Source.METALOG, "motus3",            "clade")
    SPIRE_MOTUS        = ProfilerSpec(Source.METALOG, "spire_motus",       "clade")
    METAPHLAN4_ALL     = ProfilerSpec(Source.METALOG, "metaphlan4_all",    "clade")
    METAPHLAN4_SPECIES = ProfilerSpec(Source.METALOG, "metaphlan4_species","clade")

    def spec(self) -> ProfilerSpec:
        return self.value

B.3 The wiring point — Settings & Runtime

Settings validates on construction (fail fast). Runtime is the one place concretes are named; it builds wired services on demand. The facade reads one module-level Runtime set by config() — the Program.cs of this package.

@dataclass(frozen=True)
class Settings:
    db_path: Path
    llm: str
    llm_key: str

    def __post_init__(self):
        self._require(self.db_path.exists(), "database file not found")   # fail fast at config()
        self._require(bool(self.llm_key), "missing LLM key")

class Runtime:
    def __init__(self, settings: Settings):
        self._settings = settings

    def ask_service(self) -> AskService:
        return AskService(self._translator(), self._sizer(), self._repository())

    def cohort_builder(self) -> CohortBuilder:
        return CohortBuilder(self._discovery(), self._profiles(), self._metadata(), self._factory())

B.4 Translation — Translator + GeminiBackend

Translator orchestrates; GeminiBackend is the only class that imports the Gemini SDK. The prompt is a typed DTO so the port stays at one parameter.

@dataclass(frozen=True)
class TranslationPrompt:
    question: ResearchQuestion
    schemas: str                     # every source's columns, from SchemaCatalog

class Translator:
    def __init__(self, backend: LlmBackend, catalog: SchemaCatalog):
        self._backend = backend
        self._catalog = catalog

    def translate(self, question: ResearchQuestion) -> Translation:
        prompt = TranslationPrompt(question=question, schemas=self._catalog.all())
        return self._backend.translate(prompt)

Invalid SQL is not caught here — it surfaces when CohortSizer runs the count against the DB (B.6). That keeps the network step pure and pushes "is this SQL real?" to the component that owns the DB.

B.5 Plan, PlanView, PlanRepository

Plan is a serializable document plus two thin behaviors: render (_repr_html_ → PlanView) and run (sugar over the active Runtime's CohortBuilder). The on-disk form is the Plan: JSON via asdict. The profiler is not stored — it is a run() argument.

@dataclass(frozen=True)
class Plan:
    question: ResearchQuestion
    translation: Translation
    preview: CohortPreview
    error: str | None = None

    def run(self, profiler: Profiler, out: Path) -> biom.Table:
        self._guard_runnable()                       # guard clause, no else
        return active_runtime().cohort_builder().build(self, profiler, out)

    def _guard_runnable(self):
        if self.error is not None:
            raise TranslationError(self.error)

    def _repr_html_(self) -> str:
        return PlanView(self).render()

Tradeoff, stated honestly: run() reaches the module-level runtime (a service locator), coupling the DTO to global config. The alternative — a RunnablePlan bound to services on load — was rejected as ceremony: the plan file must run from a bare load_plan(path), so the runtime is ambient anyway. CohortBuilder.build(plan, profiler, out) stays the pure, injectable entry point; run() is sugar over it.

class PlanRepository:
    def __init__(self, root: Path):
        self._root = root

    def save(self, plan: Plan, path: Path | None) -> Path:
        target = self._resolve(path, plan.question)   # explicit save= or plans/<slug>.json
        target.write_text(self._encode(plan))
        return target

    def load(self, path: Path) -> Plan:
        return self._decode(path.read_text())

B.6 AskService & CohortSizer

class AskService:
    def __init__(self, translator: Translator, sizer: CohortSizer, repository: PlanRepository):
        self._translator = translator
        self._sizer = sizer
        self._repository = repository

    def ask(self, question: ResearchQuestion, save: Path | None) -> Plan:
        translation = self._translator.translate(question)
        plan = self._planned(question, translation)
        self._repository.save(plan, save)
        return plan

    def _planned(self, question: ResearchQuestion, translation: Translation) -> Plan:
        preview = self._sizer.preview(translation)
        return Plan(question=question, translation=translation, preview=preview)

CohortSizer runs only cheap aggregates: a COUNT per source query, the union size, and a coverage count for every profiler (so the preview can list them all). It is also where invalid SQL is detected — the count fails, and the Plan is returned carrying error instead of a preview, so review still renders and run() refuses.

B.7 The cohort engine — CohortBuilder and its collaborators

class CohortBuilder:
    def __init__(self, discovery: CohortDiscovery, profiles: ProfileReader,
                 metadata: MetadataReader, factory: BiomFactory):
        self._discovery = discovery
        self._profiles = profiles
        self._metadata = metadata
        self._factory = factory

    def build(self, plan: Plan, profiler: Profiler, out: Path) -> biom.Table:
        cohort = self._discovery.discover(plan.translation.queries)
        matrix = self._profiles.read(profiler, cohort.union())
        metadata = self._metadata.reconciled(cohort)
        table = self._factory.build(matrix, metadata.restricted_to(matrix.accessions()))
        return self._written(table, out, DropReport.between(cohort.union(), matrix.accessions()))
ClassSignatureDomain effect
CohortDiscoverydiscover(queries) -> Cohortrun every source SELECT via Database; union accessions into a Cohort (keeps each source set distinct internally).
ProfileReaderread(profiler, accessions) -> ProfileMatrixpull the chosen profiler's table for those accessions; the matrix columns define which samples actually have it.
MetadataReaderreconciled(cohort) -> ReconciledMetadataread each source's metadata for the cohort and fold them by precedence.
MetadataReconcilerreconcile(frames) -> ReconciledMetadatafold sources by precedence (today Metalog > SRA); higher wins per accession, lower fills gaps.
BiomFactorybuild(matrix, metadata) -> biom.Tableassemble the single-feature-space table; lineage rides the feature axis.
DropReportbetween(requested, present) -> DropReportset difference: cohort accessions with no profile, reported never silently kept.

B.8 The precedence merge (the one subtle line)

Reconciliation folds the source frames by precedence. Two sources today; the fold generalizes to N. Opaque library call gets an extracted method and a why-comment (clean-code rule 5):

class MetadataReconciler:
    PRECEDENCE = (Source.METALOG, Source.SRA)        # highest wins; extend when a DB is added

    def reconcile(self, frames: dict[Source, pandas.DataFrame]) -> ReconciledMetadata:
        ordered = [frames[source] for source in self.PRECEDENCE if source in frames]
        return ReconciledMetadata(self._folded(ordered))

    def _folded(self, ordered: list[pandas.DataFrame]) -> pandas.DataFrame:
        winner = ordered[0]
        return reduce(combine_first_onto, ordered[1:], winner)   # each lower frame only fills gaps

Frames are indexed by Accession; combine_first is exactly "left wins, right fills." No hand-rolled column logic, no else. combine_first_onto is a named module function (no lambda) wrapping base.combine_first(filler).

B.9 ProfileMatrix / ReconciledMetadata — owning their invariants

@dataclass(frozen=True)
class ProfileMatrix:
    counts: pandas.DataFrame          # features × accessions, one feature space
    lineage: pandas.DataFrame         # feature → lineage; the biom feature axis

    def accessions(self) -> frozenset[Accession]:
        return frozenset(self.counts.columns)

@dataclass(frozen=True)
class ReconciledMetadata:
    frame: pandas.DataFrame           # indexed by Accession

    def restricted_to(self, accessions: frozenset[Accession]) -> ReconciledMetadata:
        return ReconciledMetadata(self.frame.loc[sorted(accessions)])

Callers never see .columns or .loc; the matrix answers "which samples do I cover?" and the metadata answers "restrict to these." The DataFrame is an implementation detail behind the type.

B.11 Testing strategy

  • Ports get fakes. FakeLlmBackend returns a canned Translation; FakeDatabase returns canned frames. Every service is unit-tested with zero network and zero disk. AAA, blank-line-separated.
  • Domain objects are pure — DropReport.between, the precedence fold, restricted_to tested directly on small fixtures.
  • One e2e wires real DuckDbConnection against a tiny fixture DuckDB (a handful of accessions across both sources, two profilers) and asserts the biom feature space, dropped set, and precedence metadata. Mirrors the existing Tests/e2e shape.
  • Plan round-trip: save → load → equal Plan; load_plan(path).run(profiler, out) never touches LlmBackend and accepts a different profiler than any earlier run.
